A hands-on MongoDB project demonstrating CRUD operations, document insertion, updates, deletion, and query operations on a student database. The project was implemented using the MongoDB Shell (mongosh) with a students collection containing 51 student records.

📌 Project Overview

This project demonstrates how MongoDB can be used to manage structured student data using a NoSQL, document-oriented approach.

Each student document contains:

rollNo
name
age
department
marks

The project covers basic database operations as well as MongoDB's comparison and logical query operators.

🛠️ Technologies Used
MongoDB
MongoDB Shell (mongosh)
NoSQL Database
JSON-like Documents
